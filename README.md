# python-tietovisa-jatkotehtava
Tässä pohjakoodi, jonka avulla laajennetaan osaamista silmukoista. Tämä on jatkotehtävä python-tietovisa-pohjakoodi osalle.

Tässä tehtävässä aiemmin tehty tietovisa toteutetaan uudelleen funktioita käyttäen. Tavoitteena on harjoitella funktioita, paluuarvoja ja ohjelman rakenteen selkeyttämistä. Testaa ohjelmaa jokaisen vaiheen jälkeen.
